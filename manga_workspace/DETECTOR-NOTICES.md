The publisher declares the model Apache-2.0. The Manga109-s dataset and its comic images are not bundled. The model card prohibits commercializing reproductions/modifications of the Manga109-s comic images and requests the following citations for published Manga109-s based results:

- Aizawa et al., Building a Manga Dataset “Manga109” with Annotations for Multimedia Applications, IEEE MultiMedia 27(2), 8–18, 2020. DOI 10.1109/MMUL.2020.2987895.
- Matsui et al., Sketch-based Manga Retrieval using Manga109 Dataset, Multimedia Tools and Applications 76(20), 21811–21838, 2017. DOI 10.1007/s11042-016-4020-z.

Python embedded distribution is downloaded from python.org; its license is included in that distribution. ONNX Runtime, NumPy, Pillow and their dependency licenses are included in installed package metadata. Packages are installed into a dedicated portable Python, not Krita or another application's environment.

The detector adapter is bundled in this extension. No Manga Bridge module, cache or executable is loaded.
