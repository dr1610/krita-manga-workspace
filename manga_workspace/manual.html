漫画ワークスペース 無料公開試作版 0.3.2-alpha

試作版：重要な原稿はバックアップを取ってから使用してください。漫画制作機能はKritaだけで動作します。AI生成には別途ComfyUIが必要です。自動検出は利用者が明示的に導入した場合だけ外部ファイルを取得します。

Krita標準の描画・レイヤー機能に、ページ管理、漫画原稿設定、コマ割り、Anima AIプレビューを追加します。プラグインを有効・無効にした後はKritaを再起動してください。

基本ワークフロー

  1. 「ファイル → 新しいドキュメント → 寸法 → 定義済み」から漫画規格を選びます。
  2. ページ管理の「漫画原稿設定…」で仕上がり、裁ち落とし、基本枠、枠線幅、コマ間隔を適用します。
  3. 初回に作られる大ゴマを「枠を分割 → 操作開始」で分割します。線はコマの外から反対側の外まで引きます。
  4. コマ一覧でコマを選び「このコマに描く」で作画します。
  5. AIを使うときは上部「AI作画」を選び、右ドックでPromptを設定します。

オノマトペ素材

メニューバーの「オノマトペ → オノマトペ素材を作成…」、または左側の「ド」アイコンから素材画面を開きます。上部のライブプレビューとスタイルカードで仕上がりを確認し、折り畳み式の「文字と縁取り」「変形と効果」「配置」で調整します。透明な新規レイヤーとして作成します。

  1. Kritaの矩形選択で配置範囲を指定するか、コマ一覧で配置先のコマを選びます。
  2. 素材画面で文字と見た目を設定し、プレビューを確認します。
  3. 配置先を「選択範囲」「現在のコマ」「ページ中央」から選びます。
  4. 「素材レイヤーを作成」を押します。現在のレイヤーがコマGroup内なら、そのコマGroupへ追加します。

既定のプリセット、フォント、色、配置先は「オノマトペ → オノマトペ設定…」で変更できます。生成処理はローカルで行い、入力文字や原稿画像を外部へ送信しません。

MANGA BRIDGE v2文字領域

  1. Kritaの矩形選択で文字を置く範囲を囲みます。
  2. AI作画の「③ 文字・オノマトペ領域を追加」を押します。
  3. 台詞／オノマトペ／効果音／モノローグ／ナレーター、文字内容、描画方法、所属コマを設定します。
  4. 「指定した文字を描く」では「この領域へオノマトペ素材を作成…」から、登録範囲へ素材を作成できます。所属コマがある場合はそのコマGroupへ追加します。

「文字を描かず空間を確保」「吹き出しを残し文字は描かない」「指定した文字を描く」の指示は、領域座標とともにAI生成用Promptへ渡します。自動検出で作られた文字領域にも同じ設定を使用できます。

外部の漫画文字素材

素材画面の「外部素材サイト」では、DDD FONT、マンガパーツSTOCK、フキダシデザインの公式サイトと利用条件を開けます。利用者自身が利用条件を確認して取得したPNG・JPG・SVGは「取得済みPNG・JPG・SVGを読み込む…」から配置できます。画像は比率を保って現在の配置範囲へ収め、コマ指定時はコマ外をマスクします。

DDD FONTその他の外部素材は、拡張機能やGitHub Releaseへ同梱せず、自動ダウンロードもしません。利用数、改変、商用利用、作品配布の条件は各配布元で確認してください。

ページ管理

単ページでも表示します。「＋追加」は保存先を尋ねず、現在の原稿設定を引き継いだ新しいページをすぐ作ります。追加後は「未保存のコミック」として、追加、複製、削除、並べ替え、前後ページ移動が可能です。保存するときだけ「⋯ → コミック作品として保存…」を選びます。保存済みページを削除しても元のKRAは復元用に保持します。

コマとレイヤー

コマは下部一覧から選択します。枠描画、分割、境界移動、コマ間隔、枠線幅を操作できます。標準レイヤードックはそのまま使用し、改名、複製、削除、表示、ロック、重ね順を管理します。画像の移動・変形とUndoはKrita標準操作を使います。

左の矢印選択ツールでCanvasをクリックすると、コマ内の絵・画像・文字をレイヤーパネルの上下順で判定し、最上位の可視レイヤーへ移ります。透明部分では下のレイヤーを選び、何も描かれていない場所ではそのコマで最後に編集したレイヤーへ移ります。標準レイヤーパネルで変更した重ね順には手を加えません。

描画、文字確定、レイヤーの表示切替や並べ替え後は、下部コマ一覧のサムネイルを自動更新します。更新によって現在のコマやレイヤー選択は変わりません。

上部のKrita標準ファイルツールバーに「↶ 戻る」「↷ 進む」があります。左端のKrita標準ツールを選ぶと、漫画拡張の矢印操作状態を解除して選択した標準ツールへ操作を渡します。

「ページ管理 → コマ一覧の配置」から、コマ一覧を下の横長、左の縦長、右の縦長へ切り替えられます。左右では操作部も縦配置になります。AI作画を表示しても標準レイヤーパネルの位置は変更しません。

上部の「漫画作画」「AI作画」「全体にフィット」は、現在のドック位置、幅、標準レイヤーやブラシの選択中タブを変更しません。「漫画作画」はページ管理とコマ一覧を現在位置で表示し、「AI作画」はAIドックを現在位置で表示します。配置を組み直す操作は「ページ管理 → 漫画用の配置に整える」を明示的に選んだ場合だけ実行します。

AIプレビュー

ローカルComfyUIを 127.0.0.1:8188 で起動します。AnimaとComfyUIへ登録された標準Checkpointをモデル欄から選べます。「更新」で一覧を再読込します。対象は「現在のコマ」「選択範囲」「ページ全体」から選べます。

AI作画が見つからない場合は、左のページ管理にある「AI作画パネルを開く ▶」を押します。上部の「AI作画」またはメニュー「ページ管理 → AI作画を表示」からも開けます。AI作画は標準レイヤーの下へ、同じ右列の横幅で表示されます。

  1. 全体Promptへ場面、構図、画風、背景を書きます。
  2. 必要なら除外Promptを書きます。
  3. Seed、Steps、Guidanceを設定します。
  4. 「AIプレビュー生成」を押します。

新規原稿には品質タグと基本除外タグが初期記入されます。日本語入力も可能です。日本語Tagは1文字、英語Tagは2文字以上入力すると候補が開き、日本語候補は英語Tagとして挿入されます。Ctrl+Spaceでも候補を表示できます。

日本語Tagは1文字から、英語Tagは2文字から候補を表示します。候補を確定すると現在のカーソル位置にあるTagだけを置換し、行頭や別の行へは移動しません。日本語IMEで文字を確定した後も候補を更新します。

候補一覧は、左に英語Tagと登録済みの日本語名、右にDanbooru利用件数をK/M表記で表示します。色は一般、作者、作品、キャラクター、メタ情報の種類を表します。表示用の日本語名や件数はPromptへ挿入せず、確定時は英語Tagだけを現在位置へ入力します。

「全体プロンプト（必須・日本語入力可）」は人物・背景・構図・画風など対象全体へ反映する内容です。「除外プロンプト（描かないもの）」は崩れや不要な要素です。長いTag列はドック幅に合わせて複数行へ折り返します。

「設定」タブではComfyUI URL、Preview長辺上限、生成待機上限、新規原稿の初期Prompt／除外Prompt、Tag補完の有効・無効と一度に表示する候補数を変更できます。表示件数は3～30件で、初期値は10件です。AI作画のモデル欄にある「⚙ 設定」、または上部の「ページ管理 → AI作画の設定…」から設定タブを直接開けます。「接続確認」でURLを試し、「保存」でKrita全体の設定として記録します。

結果は対象コマGroup内の AI Preview レイヤーへ置かれます。再生成すると同名Previewを差し替えます。残す結果は再生成前に複製または改名してください。

複数人物と物体

  1. Kritaの矩形選択で生成したい範囲を囲みます。
  2. 人物だけ・背景だけなど、その範囲だけを生成する場合は「① 選択範囲だけを生成する」を押し、開いた全体Promptへ内容を入力します。
  3. 1コマ内へ複数人物を配置する場合は、各人物を囲んで「② 人物の配置範囲を追加」を押し、自動で開いた個別Promptへ内容を入力します。物体は「物体の配置範囲を追加」を使用します。
  4. 必要な領域を追加した後、「AIプレビュー生成」を押します。

登録済みの人物・物体を後から確認するには「配置範囲を確認・選択」を押します。Canvas上の色付き番号をクリックすると、その番号と同じ先頭番号の一覧項目を直接選びます。色は追加順ではなく、人物＝桃、物体＝青、文字＝橙、コマ＝緑で固定です。通常時は選択中の範囲だけを表示し、確認モード中だけ全範囲を表示します。矩形の内側をクリックした場合は範囲から項目を判定します。該当する一覧と個別Promptへ戻り、Kritaの選択範囲も復元されます。選択後は確認モードを終了します。Esc、右クリック、左ツールの選択でも終了できます。

全体: 放課後の教室、全身の二人、漫画線画
左の女子: 左側、赤髪、紺色のカーディガン
右の男子: 右側、黒髪、白いシャツ

重なる人物矩形は中心間で分割し、属性の混線を減らします。輪郭に沿った分割ではありません。

接触する人物・物

「手をつなぐ」は双方の人物Promptへ同じ関係を書きます。片方が持つ物は人物領域へ含めます。2人が共有する物は独立した物体領域を作ります。抱擁、交差する腕、複雑な前後関係には輪郭Maskと接触部の部分再生成が必要で、現行版では未完成です。

実測上の制限：左右2人の属性分離と手をつなぐ例は生成できました。背景を強くすると一方の人物が消える例もあり、背景＋複数人物の単一生成は安定していません。実測時間は640×448、10 stepsで約45～94秒であり、リアルタイム生成ではありません。

拡張機能の更新

起動後にGitHub Releaseを確認し、新しい版がある場合はステータスバーと「ページ管理」メニューへ通知します。「ページ管理 → 拡張機能の更新…」では、現在版・最新版・変更内容を確認できます。「更新を適用」を押すと配布元、サイズ、ZIP内のパス、GitHub提供SHA-256を検証し、現行版をバックアップしてから配置します。反映にはKritaの再起動が必要です。

自動確認に失敗しても制作機能は停止しません。更新画面から再確認するか「GitHubで開く」を使用してください。0.1.1-alpha 以前には更新機能がないため、0.2.0-alpha は手動導入が必要です。

エラー時

  • 対象コマを求められた場合は下部のコマを選択します。
  • 選択範囲を求められた場合は矩形選択を作ります。
  • Anima以外で生成できない場合はモデルをAnimaへ戻します。
  • 接続エラー時はComfyUIとポート8188を確認します。
